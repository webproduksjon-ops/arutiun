# Контентные страницы

Новые русскоязычные материалы хранятся здесь как Markdown-файлы с front matter. Один файл — одна поисковая задача и один основной следующий шаг.

Минимальный front matter:

```yaml
slug: kogda-rabota-ne-zakanchivaetsya
title: Когда работа перестаёт заканчиваться
description: Спокойное объяснение перегрузки руководителя и возможных направлений работы.
section: Работа и лидерство
route: entrepreneurs.html
updated: 2026-09-12
index: true
intent: Информационный запрос руководителя о хронической перегрузке
query: как понять что руководитель выгорел
parent: entrepreneurs.html
cta: Обсудить запрос
```

Основной текст пишется после второго `---`. Перед публикацией нужно подтвердить авторство, фактическую точность, этичность формулировок, один поисковый интент, одну целевую фразу, родительскую сервисную страницу и релевантный CTA.
